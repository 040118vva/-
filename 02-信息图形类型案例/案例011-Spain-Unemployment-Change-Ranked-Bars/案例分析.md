# 案例011：西班牙各区域失业率月环比变化（地图+排序条形图）

## 01 主导数据逻辑
**地理图形型（Geographical）**。地图按西班牙区域呈现数值与相对平均值关系，空间单元是主要数据对象。右侧排名条形图为辅助比较模块。

## 02 案例标签
- 区域统计地图 + 排序条形图
- 地图—排名联动的双视图信息图
- 正负变化/基准比较条形图（以图中标注值为依据，零基线用于方向区分）
- 外置排名列表与地图定位

## 图面特性
- 左侧西班牙区域地图，采用深灰紫与浅紫灰两类色彩区分高于/低于图示平均值（图中平均值标为 +0.82）；该分类阈值及统计含义按图面识读记录，原始口径仍待核验。
- 右侧按数值从高到低排列19个地区，横条以零基准区分正负方向，条长表达数值绝对幅度，正值向右、负值向左。
- 数值在条形右侧直接标注，省去读者从轴线估读。
- 排名排序和地图空间位置形成双重阅读：右侧快速比较，左侧查看空间分布。
- 虚线横向导引/分隔帮助逐项追踪行条目。
- 地图与榜单采用一致的高/低平均值颜色语义，构成跨视图联动。

## 视觉编码
| 元素 | 编码/作用 |
|---|---|
| 区域地图面 | 空间定位 |
| 深色面/深色条 | 高于图示平均值的类别（图例视觉识读） |
| 浅色面/浅色条 | 低于图示平均值的类别（图例视觉识读） |
| 横条长度 | 变化数值幅度 |
| 横条方向 | 正负方向 |
| 排序 | 从高到低的比较顺序 |
| 数值标签 | 精确读数 |
| 细虚线 | 行追踪/条目分隔 |
| 引线/边界 | 地图区域定位与空间识别 |

## 信息架构
标题与指标说明 → 左侧地图（空间概览） → 右侧排序条形图（精确比较） → 平均值色彩说明。地图和排名视图通过一致的区域数据与颜色类别关联。

## 视觉叙事
空间总览 → 从最高正向值向下浏览排名 → 观察接近基准的地区 → 进入负值区域 → 识别极端变化。排序条形图强调差异幅度与正负方向，地图揭示差异的空间位置。

## 制作方法（根据图面推演，非作者真实流程）
1. 核验区域清单、月份、指标定义、单位和数据来源。
2. 建立包含区域代码、名称、数值及来源的表格。
3. 计算/核验图示平均值与正负基准，明确图例分档规则。
4. 以区域代码连接统计数据与西班牙区域底图。
5. 制作地图分色；对地图色彩语义建立明确图例。
6. 将数据按值降序排列，生成带零基准的水平条形图。
7. 将正值条向右、负值条向左，条长按统一比例尺映射。
8. 直接标注数值，添加水平行分隔/追踪虚线。
9. 统一地图与榜单的色彩类别，排版成地图—榜单双视图。
10. 核验数值、区域对应关系、排序、基准、色阶及图例。

## 基础数据集说明
CSV中的数值从用户提供的图像转录，保留地区英文/图中简称和数值；数据来源、统计口径、基准计算方法未独立验证。图示平均值为 +0.82，记录为视觉标注，不将其解释为已验证的官方平均计算。数据单位按图中文字“环比变化百分比”暂录为百分点/百分比变化表述，仍需源文核验。

## 复现要点
- 排名条形图应保留零基线与正负方向。
- 使用同一尺度比较正负值。
- 数值直接标注，避免依赖估读。
- 地图色阶与条形颜色的阈值语义需一致并有图例。
- 不要把“失业率变化”误读成“失业率水平”。
