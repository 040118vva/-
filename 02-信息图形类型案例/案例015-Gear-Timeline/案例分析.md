# 案例015｜Gear Timeline（个人成长与设计影响时间线）

## 01｜五类主导数据逻辑
**主导逻辑：编年型（Chronological）**。时间段、时间节点与个人经历沿连续蛇形/齿轮式路径推进，时间是结构主轴。路径采用非直线、连续弯曲的分段环形结构，多个阶段依次串联。

## 02｜案例标签
- 螺旋/蛇形连续时间线
- Gear Timeline（齿轮式/环段时间线，名称为作者标签）
- 个人成长时间线 / autobiographical timeline
- 多尺度分段时间线
- 时间线 + 书籍/设计影响条目
- 未来展望段

## 主题与内容
图面题名为 Gear Timeline，展示作者个人经历及影响其图形设计学习/兴趣的书籍或设计事件。图中阶段标记包括：1987–2000、2000–2006、2006–2010、Yulin: 2010、2010、Now Yulin: 2011，以及 Future 2012。图中还出现 Kindergarten、Elementary school、High School、College、Grad School、Summer Vacation、Poster、Typography、Graphic Design 等阶段或主题标签。周围的放射式短刻度、细引线、文字条目列出年份、日期或书籍/设计相关记录；部分细文字无法可靠识读。

## 特性
- 连续宽彩带/蛇形环带串联不同时间阶段，呈现时间的流动与阶段转换。
- 各阶段以大圆形或环形中心区域留白，中心直接标阶段时间/地点。
- 主路径由蓝、青、绿渐变/相邻色带组成，视觉上有连续性，并局部切换色段区分阶段。
- 时间事件在环形外缘用短刻度、径向细线和外置文字标记；部分年份以蓝色突出。
- 环带周围出现阶段名称，贴合环带排布；外侧条目采用引线或径向布局，形成密集的事件目录。
- 既有阶段跨度（如1987–2000），又有具体年份/日期事件，形成多尺度时间信息。
- 主路径从左上向中部、下部、右侧蜿蜒延伸，阅读顺序依路径推进；非标准直线轴，需要标题、阶段标记及方向线索辅助。
- 末端 Future 2012 以开放的环形轨迹呈现未来展望，路径视觉上延续但尚未闭合。
- 左下角说明文字介绍作者回顾人生、将不同人生片段联系起来，以及书籍对其设计兴趣的影响。
- 右上角小蓝框为项目/课程身份说明（图面文字：Information Design / MOE scholarship program 2011）。

| 元素 | 编码/作用 |

| 蓝—青—绿色段 | 路径视觉连续性及阶段区分；颜色语义需依图面标签解读 |
| 放射刻度/细线 | 时间事件的细分定位、引导线 |
| 外侧文字 | 事件、书籍、设计影响及日期 |
| 蓝色年份/日期 | 时间标记突出 |
| 环带上的阶段标签 | 学校、生活或设计阶段 |
| 中心年份/地点文字 | 阶段标识 |
| 开放环形末端 | 未来展望/未完成时间 |

## 信息架构
标题/项目标签 → 连续蛇形环带主时间轴 → 大阶段中心标识 → 外缘事件/书籍/设计影响条目 → 个人地点/阶段提示 → 左下叙事说明 → Future 2012 终段。时间线本体优先，事件目录和说明模块为辅助。

## 视觉叙事
“出生/早期经历（图面以 Born 及1987–2000段提示）→ 学校与个人成长阶段 → 高中/大学/设计学习阶段 → 2010及Yulin相关个人节点 → 2011当前状态 → Future 2012”。通过沿彩带移动完成时间阅读，外缘条目将书籍、设计、学习和事件影响补充到阶段之间。叙事由回顾过去逐渐过渡到当前和未来。

## 制作流程（图面推演，非作者真实流程）
1. 确定叙事主题：个人经历、成长阶段与设计影响。
2. 建立事件数据表：日期/年份、阶段、事件、地点、事件类别、来源、标签文本。
3. 将事件按时间排序，合并成可读阶段（如学习阶段、生活阶段、设计经历）。
4. 设定时间精度：阶段跨度与具体事件日期并存；明确哪些属于阶段、哪些是单点。
5. 规划整体蛇形/环形路径，设定时间阅读方向、阶段转弯与路径间距。
6. 绘制连续彩带主轴，按阶段切换颜色或渐变；确保视觉连贯。
7. 为大阶段设计中心留白圆区，放置阶段时间或地点文字。
8. 将阶段名称放在环带内侧/表面，沿曲线方向排版。
9. 在环带外围生成事件刻度与径向引线，按事件日期分配位置。
10. 排布事件文字，调整旋转角度、引线长度、字号、间距，处理碰撞。
11. 对关键年份/日期采用颜色、字号或位置强调，控制强调数量。
12. 加入书籍/设计影响条目、地点地图轮廓、说明文本和项目标识。
13. 设计未来段为开放轨迹，明确未来时间属于预测/规划而非已发生事件。
14. 校验时间顺序、阶段边界、日期、标签、事件来源和文字可读性。
15. 导出并归档可编辑路径、事件数据表、字体、颜色和源文件。

## 基础数据集
- `timeline_event_transcription.csv`：图面可识别的阶段、年份、事件/主题标签与置信度。细文字未识读部分不猜、不补。
- `visual_encoding_transcription.csv`：时间轴路径、刻度、标签、颜色、环段、叙事与视觉编码观察。
数据为图像转录/观察，非作者完整原始事件数据库。具体事件标签与日期需核验。

## 可复用风格策略
- 使用连续蛇形彩带替代直线时间轴，形成路径感与情绪连续性。
- 以大阶段环段/中心圆容纳阶段名称和跨度。
- 将细事件置于外围刻度与引线，建立主阶段—事件条目的层次。
- 采用渐变或相邻色带跨阶段连接，但阶段边界保持可识别。
- 结合个人地点、地图轮廓、书籍/设计条目，形成个人叙事。
- 末端用开放轨迹表达未来展望。
- 通过中心留白和外缘密集事件，平衡主轴可读性与资料丰富度。

## 风险与限制
- 非线性空间路径容易产生时间方向歧义，需标明起点、顺序与阶段。
- 放射文字密集、旋转角度多，缩小后可读性下降。
- 时间间距不一定按比例，若非比例应说明，避免误读为精确时间尺度。
- 渐变色不应成为唯一的阶段辨识方式。
- 图面日期/事件细节有限，需原始数据核验。
