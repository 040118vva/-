# 案例014｜Old World Language Families（旧世界语言家族）

## 01｜五类主导数据逻辑
**主导逻辑：层级型（Hierarchical）**。主体用树干、枝干、枝条和叶/语言标签表达语言家族、分支与语言之间的从属/谱系关系。树状拓扑是核心数据结构；枝条大小另编码人口规模，地图插图补充语言族群的历史扩散地理。

## 02｜案例标签
- 语言谱系树 / Language Family Tree
- 树形层级信息图 / Tree Diagram
- 人口规模辅助编码的谱系图
- 谱系结构 + 历史地理扩散双视图
- 手绘树形隐喻 / Illustrated Tree Infographic

## 图面内容
标题为“Old World Language Families”，主图为树形谱系概览。图面说明指出：上半部枝条大小代表公元0年之前记录的母语使用者规模；下半部展示已知现存语言族群的近似人口规模（比较基准为公元0年，图中文字说明有些斯卡尔德语者还保留解读其他旧世界语言的能力，原文表述需谨慎核验）。画面中央还嵌入历史传播地图，图注说明以箭头/颜色展示 Indo-European、North Germanic、Uralic、Finnic 等历史扩散方向/区域。

## 视觉特征
- 以一棵巨型树作为图形隐喻：树干、主枝、次枝与枝端标签构成谱系层级。
- 深色粗枝承载语言家族/分支名称；较小的枝条和标签表达细分谱系或语言。
- 上半部偏深青蓝色叶簇/枝叶与米色底形成古典、自然史风格。
- 主枝文字沿枝干方向旋转排布，使标签融入树的形态。
- 树形主图覆盖语言族群和谱系结构，强调由家族到分支到语言的层级关系。
- 枝条尺寸用于人口量比较，属于层级与数量的复合编码；图注说明上部数据为公元0年之前记录的母语者规模，数据细节、时间与估计方法未核验。
- 下半部分用更浅色的语言标签叶形/树冠构成现存语言人口规模的比较组件，枝/叶面积近似编码人口量。
- 两个世界地图小面板补充历史扩散范围，形成树形谱系与空间传播的互补视图。
- 采用米色纸张纹理、深海蓝背景/枝干、青蓝色、黑色及浅色字体，构建复古图鉴/自然史插画质感。
- 文字密度高；大小字号、沿枝标签、留白区标题及小地图帮助形成多层阅读。

## 视觉编码
| 元素 | 编码 | 作用/限制 |
|---|---|---|
| 树干 | 主语言家族/总体谱系 | 隐喻总结构 |
| 主枝/分枝 | 家族与子分支层级 | 亲缘/从属结构 |
| 枝端标签 | 具体语言或分支名称 | 识别 |
| 枝条/叶簇面积或尺寸 | 图注所述人口规模 | 数量编码；确切尺度映射需核验 |
| 颜色 | 分组/视觉区分，地图上有历史扩散说明 | 不将颜色独立推断为人口或地理 |
| 沿枝文字 | 分支名称 | 结构与标签融合 |
| 两幅地图 | 历史扩散地理 | 辅助空间视图 |
| 叶形/树冠 | 语言标签/群组容器 | 视觉隐喻 |
| 米色纹理 | 背景 | 复古风格 |
| 深蓝/青色 | 树、分支、背景与群组 | 视觉层级、分区 |

## 信息架构
标题/说明 → 上半部旧世界语言家族谱系树（枝条尺寸说明）→ 中部历史扩散地图及说明 → 下半部现存语言人口规模的树状/枝叶分布 → 细语言标签。主图谱系为主体，地图与人口规模视图为辅助模块。

## 视觉叙事
从整体语言家族树干开始，沿主枝追踪大类，继续向次枝和具体语言展开；通过枝条大小感知历史人口规模；再通过地图理解历史传播区域；最后在下半部观察现存语言及近似人口规模。叙事路径为“总体谱系—分支关系—语言细项—数量规模—历史扩散—现存分布”。

## 制作流程（根据图面推演，不代表作者实际流程）
1. 确定主题范围：旧世界语言家族、语言谱系及历史/现存人口比较。
2. 建立语言谱系数据：家族、分支、语言、上级节点、分类依据与来源。
3. 收集人口规模估计数据，明确公元0年前历史估计与现存人口的定义、时期、口径及不确定性。
4. 整理历史扩散区域与地图数据，核验地图范围和扩散路径。
5. 建立树形层级结构，确定主干、主枝、次枝、枝端节点和层级深度。
6. 将语言家族与分支名称安排在枝干上，沿枝方向旋转标签；为细节点设置标签层级与可读性策略。
7. 将人口规模映射到枝条/叶簇尺寸，确定尺度、最小/最大尺寸与面积映射原则。
8. 选择颜色分支编码，保持谱系颜色与地图颜色语义一致或明确分离。
9. 绘制历史扩散地图小面板，补充空间信息但避免地图抢占谱系主视觉。
10. 设计下半部现存语言人口规模视图，保持同一主题下的层级结构与视觉风格。
11. 整合标题、图注、人口口径、数据来源、说明文字、纹理、插画及版面。
12. 校验谱系关系、人口数据、标签、颜色、地图与图例，归档源数据与图形文件。

## 基础数据
见 `language_family_tree_transcription.csv`。该表只转录图中可辨识语言/分支名称、所属家族（按图面推断）、显示区段与识读置信度，非完整谱系数据库；无法可靠辨识的标签不扩充。见 `visual_encoding_transcription.csv` 记录编码说明与图注数据口径。人口数值未从图像可靠恢复，不以假数值填充。

## 风格提炼
- 用树的形态把抽象谱系层级自然化、具象化。
- 树干粗细、枝分叉、枝端标签同步承担结构表达。
- 沿枝方向放置文字，使文字成为图形构造的一部分。
- 将数量编码嵌入枝/叶尺寸，兼顾谱系与人口规模。
- 以地图插图补充树形结构难以表达的空间扩散信息。
- 用古典纸纹、自然史插画、深青蓝色调和复杂标签建立图鉴感。
- 高密度信息需要清晰的层级、标签筛选和可读性控制。

## 证据限制
仅依据用户提供图片和图中文字说明。原始数据、谱系数据库、人口估计、地图来源与作者制作过程未独立核验。人口规模映射和标签的部分内容模糊，基础数据仅做有限图像转录与编码记录。
