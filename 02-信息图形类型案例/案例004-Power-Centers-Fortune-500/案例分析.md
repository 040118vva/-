# 案例 004：Power Centers of the Fortune 500

- 案例标题：Power Centers of the Fortune 500
- 来源标识：Fortune，June/July 2020（图面署期）
- 作者署名：Nicolas Rapp（图面署名）
- 案例序号：建议以入库序列管理
- 主导数据逻辑（01）：**地理图形型（Geographical）**
- 案例标签（02）：**混合型信息图（Mixed Infographics）**；兼具地图、排名、气泡符号和连线注释
- 主题：美国主要都市区中 Fortune 500 企业累计营收的地理集中情况
- 图面标示的数据：前15个都市区及其累计营收；地图上另以点标识至少拥有一家 Fortune 500 企业的都市区（图内说明）
- 注意：图面数值与排名按视觉读取转录，可能存在识读误差。纽约标示 $1.775 trillion，其他标签均为亿美元/十亿美元级别。数据CSV为图面转录数据，不等于独立核验的原始统计数据。

## 1. 分类判断

### 01 主导数据逻辑：地理图形型
地图及地理位置为作品核心空间参照。都市区数据通过空间连线定位到美国地图上的点，回答经济力量分布于哪些地理位置的问题。虽然顶部形成价值排名和圆形符号比较，但空间定位和区域分布仍主导整体阅读。

### 02 案例类型：混合型信息图
作品组合：
- 美国地理地图及都市区定位点
- 以圆形大小呈现都市区累计营收的气泡符号
- 从气泡/标签到地图地点的连接线
- 排名、数值标签和标题
- 地图点分布提示及底部说明文字

## 2. 图形特性

1. **地图与排名双空间布局**：地图占下部主体，排名/数值气泡在上部周边排列，减轻地图标注拥挤。
2. **跨空间连接**：曲线连接上方排名符号与地图位置，建立“指标—地点”的对应关系。
3. **大小编码**：圆形大小视觉上编码都市区累计营收（需以原始数据确认具体比例尺度；图面未充分说明尺度）。
4. **地理点集**：地图上的小点呈现都市区/企业分布密度或相关位置（图面文字称每个点代表至少有一家 Fortune 500 公司的都市区；点位与数量需谨慎核读）。
5. **强弱对比**：深色气泡、细暗线、浅色地图及背景构成层次；纽约的白色气泡形成视觉突出。
6. **文本信息分层**：顶部标签提供排名城市与数值；主标题、解释性段落及来源署名形成底部阅读区。
7. **叙事**：标题先提出“财富500强权力中心”，随后地图揭示空间分布，气泡突出都市区差异，底部文字解释纽约的领先与其他地区的竞争/增长。

## 3. 视觉编码拆解

| 视觉元素 | 作用/推断 | 注意事项 |
|---|---|---|
| 美国地图轮廓 | 提供地理参照 | 地图投影及尺度非重点但应保持空间准确 |
| 地图上的小点 | 标示图面说明中的都市区位置 | 不应推断为企业数量，除非数据说明支持 |
| 大圆气泡 | 编码都市区累计营收 | 具体面积/半径比例与计算方式需原始数据确认 |
| 曲线连接线 | 连接排名符号与地图位置 | 交叉线较多；可优化线弯曲与透明度 |
| 城市名称、数值 | 直接标注对象和量值 | 标注单位需统一 |
| 白色突出气泡 | 强调纽约 | 颜色强调可能使读者将突出理解为特定类别/焦点 |
| 标题与正文 | 组织解释和叙事 | 正文较密集，缩小后可读性有限 |

## 4. 信息架构

- 上层：标题与时间/刊期线索。
- 上部环绕区域：排名气泡、城市名与数值标签。
- 中下层：美国地图与地理点集。
- 连线层：跨空间定位对应关系。
- 下层：主标题、解释性正文、署名。

## 5. 视觉叙事结构

**主题引入 → 排名与营收差异 → 地图空间定位 → 分布密度/地理聚集 → 文字总结与观点**

作品不是纯地图统计图，而是用排名信息与空间位置协同叙事。读者可先扫上方城市价值，再沿线追踪地图位置，最后阅读解释段落。

## 6. 制作方法与流程（可复现建议）

### 数据准备
1. 建立都市区名称、营收值、排名、地理坐标、地图位置等字段。
2. 整理美国都市区/地理底图，统一地理坐标体系。
3. 对数值排序，确定展示前15名。
4. 单独准备地图点集数据（如作品所述：至少拥有一家 Fortune 500 公司之都市区），与排名数据区分。

### 数据与编码
1. 先决定气泡面积映射营收值的尺度（面积而非直径更符合数量比较原则；图面具体比例未经确认）。
2. 将排名气泡与地图坐标建立匹配关系。
3. 为气泡位置设计标签避让和连接路径；优先减少线交叉。
4. 地图底层点集采用低对比度，避免压过主数据。
5. 突出重点城市，使用直接标签和数值。

### 版式制作
1. 地图置于下半部/中心，保留周边空间。
2. 将排名符号放在地图外围，城市标签贴近气泡。
3. 使用曲线连接符号与地图位置，避免线穿过重要标签。
4. 建立标题、正文、署名的层级。
5. 进行缩小尺寸测试、标签重叠检查及色彩对比检查。

### 可用工具（建议）
- 数据整理：Excel、Google Sheets、Python/Pandas。
- 地理处理：QGIS、GIS数据或地图矢量编辑。
- 视觉排版与曲线/标注：Illustrator、Figma；也可结合Python绘图与矢量后期。
- 以上为复现建议，并非对原作者实际工具链的断言。
