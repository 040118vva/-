# 案例007｜Sokak Bakışı 1：街道立面与地块编目

## 01｜五类主导逻辑
**编目型（Catalog）为主导。** 图面将沿街建筑作为逐项记录对象，照片、建筑/库存编号（Envanter No）、登记编号（Ada No）与地块编号（Parsel No）组合成可识别、可检索的条目。主要目的似乎是记录与比较街道建筑，而不是展示数值统计。

**辅助逻辑：地理/空间逻辑。** 条目按街道沿线及相邻地块顺序排列，空间邻接与街道位置关系是布局的重要线索，但没有常规地图坐标或地图底图。**编年逻辑不是主导**：图像并未明显表达时间序列。

## 02｜案例标签
**街道立面编目图 / 街景建筑档案带（Streetscape Catalog / Building Frontage Inventory Strip）**。以建筑摄影条目、地块标识和横向沿街排列构成的视觉索引。

## 主题与内容识读
图片标题“Sokak Bakışı 1”（土耳其语，字面可译为“街道视角/街景观察1”）。黑白建筑照片拼接成沿街连续视觉带，虚线分隔线用于标示建筑/地块条目边界。每条目下方附登记信息。
图面可读信息包括：
- Envanter No（库存/登记条目编号）：图中多个条目显示1、2、3、4、5、6、7等编号。
- Ada No（街区/地块组编号，土耳其城市规划语境）：图中多处显示194或196。
- Parsel No（地块编号）：图中14、13、12、11、10、9、8等。
- 中间纵向标注可辨认“Sokak …”街道名称，但文字因图像分辨率及裁切无法可靠完整识读，保留不确定性。
图像中编号可能出现重复或与建筑条目分组对应；本转录仅记录可见文字，不推断编号体系的完整语义或登记规则。

## 视觉特征
- 横向宽幅构图，照片沿街连续排列，形成建筑立面长条序列。
- 建筑照片以黑白处理，统一视觉色调并突出立面形态、体量、窗门、檐口及建筑细节。
- 照片采用交叠、错位或裁切方式拼接，呈现街道观察与摄影采集感。
- 黑色粗虚线竖向分隔条目/空间段落，强化条目边界、沿街节奏及编号定位。
- 下方信息文本以小字号、左对齐分组呈现，作为照片条目的索引元数据。
- 图片顶部标注“Sokak Bakışı 1”，底部留白承载编号信息；黑白照片与白底、黑色虚线构成低干扰的档案式视觉风格。
- 没有明显定量图表或图例，主要是摄影与编号信息的编目表达。

## 视觉编码
| 视觉元素 | 编码方式 | 作用 |
|---|---|---|
| 建筑照片 | 黑白影像、裁切拼接 | 记录对象外观并供视觉比对 |
| 横向位置 | 沿街顺序排布 | 表示条目排列与空间序列（非严格地图比例） |
| 黑色竖向虚线 | 分隔条目/边界 | 形成建筑档案单元及阅读节奏 |
| Envanter No | 数字文本 | 识别条目/记录编号 |
| Ada No | 数字文本 | 记录街区/地块组相关属性 |
| Parsel No | 数字文本 | 记录地块属性 |
| 街道名称 | 纵向文字 | 补充街道/场所属性 |
| 黑白色调 | 灰阶照片 | 统一视觉语言、降低颜色干扰 |

## 信息架构
**街道序列 → 建筑照片条目 → 编号/地块属性 → 条目定位与检索。**
将横向图像带视为街道沿线的连续视窗；分隔线划定条目，照片与下方文本绑定，形成一套建筑档案卡片的带状版本。

## 视觉叙事
不是故事型叙事，而是**沿街浏览/索引式叙事**：读者从左至右查看街道空间中的建筑，逐条对照建筑照片与编号，理解沿街建筑的连续性、差异和地块序列。其阅读节奏来自照片尺度、分隔线和编号信息。

## 制作方法与流程（推演）
1. 确定街道、观察范围、记录目的及档案字段。
2. 现场按街道方向拍摄建筑立面，尽量保持摄影角度、覆盖范围、编号与空间顺序一致。
3. 采集建筑/登记编号、Ada、Parsel、街道名称等属性；校验数据与照片对应。
4. 按沿街顺序整理照片与记录表，保留相邻地块关系。
5. 统一照片灰阶、裁切和尺寸，避免对建筑细节造成误删。
6. 在版面中按序排列照片，可轻微交叠以模拟连续街景；建立条目边界与留白。
7. 使用竖向虚线或边界符号分段，并将登记信息固定在照片下方。
8. 添加标题与必要的街道标识；不添加无依据的统计或关系编码。
9. 校验照片与编号/地块数据、沿街顺序和文字准确性。
10. 导出横向长幅图，归档照片源、元数据表及来源许可。
