# 信息列表型信息图（Informational / List Infographics）

## 类型定义
以条目、清单、步骤、提示、事实或短信息单元为主要内容，通过列表、卡片、编号、分组、标签或网格形成易扫描、易理解的表达。列表可有顺序（流程、排名、步骤）或无顺序（集合、提示、要点）。

## 判定要点
- 内容由相对独立的条目构成。
- 条目组织方式明确：编号、分组、排序、标签或网格。
- 视觉层级支持快速浏览与定位。
- 若时间、空间或层级关系成为主导，仍需归入对应数据逻辑，而不只依据列表外观。

## 分析框架
1. 主题、受众、目的、核心信息。
2. 条目数量、内容粒度、属性及分组依据。
3. 排序与导航规则。
4. 条目视觉模板、图标、文字、颜色、编号及辅助图形。
5. 信息架构：列表、网格、卡片、分栏、分组。
6. 阅读节奏、密度、叙事是否线性。
7. 可读性、可检索性、易用性与误读风险。
