# 案例013｜The 2014 Quebec Political Twittersphere

## 01｜五类主导数据逻辑
**主导逻辑：编目型（Catalog）中的关系网络编目/网络结构表达。** 五类分类体系暂未设置独立的“关系网络型”；本图以用户节点集合、转推关系边及社群结构为主体，不存在地理坐标或明确父子层级，也不是时间轴。按现有五类，编目型最接近，记录为“编目型—关系网络子标签”，并注明分类体系边界与复合性。

## 02｜案例标签
- 社交网络关系图（Social Network Graph）
- 政治转推网络（Political Retweet Network）
- 力导向网络图（Force-directed Network Visualization）
- 社群聚类网络（Community Cluster Graph）
- 节点大小编码影响力的关系网络

## 图面说明（来源于图中说明文字）
图示覆盖2013年10月至2014年3月间使用魁北克主要政治hashtags的Twitter用户。说明文字称：每个点代表Twitter用户（共6,052个），每条线代表一次转推（总计119,831条）；节点大小与用户被转推频率成比例。网络布局将用户拉向其转推的用户，并远离其未转推的用户。颜色表示通过网络算法确定的较大网络内的子社群。

## 视觉特征
- 6,052个节点、119,831条关系构成高密度网络图，呈现大量细线、微小点与局部团簇。
- 节点大小表示被转推频率（图注说明），突出高影响力/高被转推账号。
- 边表示转推关系，网络布局与关系方向相关；图注提到pull toward / push away机制，具体算法参数未说明。
- 颜色编码社群/子群，不是党派或政治立场的直接编码；仅凭颜色不能推断立场。
- 三个明显的大色群/区域在图面上形成视觉分区：左侧黑灰、右侧深蓝、中心/交界附近青色。颜色簇为图像观察，算法社群标签和政治归属未核验。
- 重要节点名称被标注，普通节点以小点呈现；标签密度较高处重叠，构成视觉层次。
- 大节点、密集边与群落位置形成中心—外围结构，但中心性指标/算法排序未明示，不能仅按布局推断精确排名。
- 画布留白浅青色，网络结构作为主要图形，左上大标题与右侧解释文本/底部品牌信息形成辅助层级。

## 视觉编码
| 元素 | 编码 | 意义/限制 |
|---|---|---|
| 节点 | Twitter用户 | 网络参与者 |
| 节点大小 | 被转推频率 | 依据图注，数值映射范围未提供 |
| 边/线 | 转推关系 | 具体方向是否可见、是否加箭头未知 |
| 节点位置 | 网络布局算法 | 关系结构的空间化，非地理位置 |
| 节点颜色 | 网络社群 | 识别子群，不能直接解释为党派 |
| 标签 | 重点账号名称 | 节点识别，未标注全部用户 |
| 线密度/团簇 | 关系活跃与局部结构的视觉效果 | 线交叠不能直接当作定量边权 |
| 大标题 | 主题 | 主题入口 |
| 右侧说明 | 方法/范围/规模 | 图例之外的解读说明 |

## 信息架构
主题标题 → 网络整体 → 社群色群 → 重点节点/高被转推账号 → 右侧解释与数据范围 → 品牌标识。图面没有独立坐标轴或地图底图；空间是算法生成的关系空间。

## 视觉叙事
整体网络概览 → 观察颜色分群 → 识别各群中的显著节点 → 观察跨群连线与联系 → 阅读图注了解时间范围、节点/边数量和布局解释。图形呈现结构性探索叙事，未明确给出政治观点或因果结论。

## 制作流程（图面推演，非作者实际记录）
1. 定义研究问题、hashtags范围、日期范围（图示2013-10至2014-03）与采集策略。
2. 收集Twitter用户、转推事件及时间戳，记录API/数据获取限制与伦理考虑。
3. 清洗数据：去重、过滤研究范围、规范用户标识，定义一次转推对应的关系记录。
4. 建立节点表（用户属性/转推被接收数量等）和边表（转推者、被转推者、事件时间/次数）。
5. 选择网络分析范围与社群算法；计算或提取社群分组。
6. 设置布局算法，按网络关系形成非地理位置；布局参数需记录。
7. 将节点大小映射到被转推频率，设置尺度、最小/最大尺寸和可读性。
8. 将社群映射到颜色，确保颜色可区分并避免把颜色等同政治立场。
9. 对重要节点进行标签筛选，避免全部标注导致文字拥挤。
10. 调整边透明度/细度、背景、群落空间、标签与说明模块。
11. 校验节点、边总数、节点大小映射、群落解释、时间范围与来源，输出图形。
12. 归档数据、脚本、布局参数、社群算法、来源及隐私/许可限制。

## 基础数据
图像说明提供网络总量（6,052用户、119,831条转推）和范围。无法从图像可靠提取全部节点与边，也无法核验完整节点标签、节点数值及社群成员。本案例附 `network_metadata_transcription.csv`（可核验图注元数据转录）和 `visible_node_observations.csv`（仅对图面可见的部分标签/群色作观察记录，不完整，不含精确节点值）。不得把它们当作完整原始网络数据。

## 风格策略提炼
- 以力导向或类似关系布局将抽象转推网络空间化；位置非地理意义。
- 社群颜色强化结构分块，限制色数以避免混乱。
- 节点面积突出被转推频率，结合标签让重要用户可识别。
- 大量弱视觉细线/小节点作为结构背景，重点节点形成视觉锚点。
- 解释文本明确节点、边、时间范围与尺寸含义，帮助理解网络图。
- 线密度与重叠会影响可读性，建议降低边透明度、筛选标签或分层交互。
- 社群颜色、节点大小和布局位置必须分别解释，避免混为政治立场、排名或地理位置。

## 限制与证据
分析以用户上传图像及其图注文字为基础。原始数据、完整网络、算法、hashtags清单、作者源码及具体参数未获取；不尝试推测个人政治立场。图像中节点名称只做可读范围内观察，不用于推断政治属性。
