# 案例009｜Infographic Elements—环保/能源主题图形元素模板

## 01｜五类主导数据逻辑判断
**编目型（Catalog）为主导。** 该图是信息图组件/图表/图标模板及模块集合，并非一套可确认的真实统计数据或单一变量关系。图表、符号、地图等作为可复用组件样本，整体以元素展示、分类浏览和模块组合为主。

**辅助逻辑：混合型表达。** 同时包含示意插画、圆形比例图、点阵、条形图、面积图、柱状图、地图和重复符号阵列。右侧图标栏及各图表模块构成元素库。主题似乎指向生态、能源、运输或工业环境（从图标与“eco/bio”字样观察）；Lorem ipsum占位文字不能确认实际主题或数据。

## 02｜案例标签
**信息图组件元素模板 / Icon-led Modular Infographic Elements Template**。辅助标签：模块化版式、图表组件集合、环保/能源图标集、重复符号图、占位数据图表。

## 图面特征
- 模块化版面：主插画与下方图表模块分区，右侧纵向图标栏独立成列。
- 主插画/场景：大型机械/工业设施、城市剪影和地下/深色区域，承担视觉吸引和主题氛围，不是数据编码。
- 多图表样本：圆形比例图/饼图、点阵、横向条形、面积图、柱状图、地图与重复条目阵列。
- 符号重复阵列：货币箱、车辆/燃油符号、工业设施、植被/生态图标等，可能演示单位符号或数量阵列，但编码未说明。
- 图标索引栏：右侧纵列收集环保、工业、运输、能源、自然等图标（分类为视觉观察推断）。
- 色彩：深蓝/炭蓝背景，灰蓝辅助，浅色图标形成高对比，有限色调保持统一。
- 文本：标题、短描述、模块标题和占位文本；信息层级清晰但内容不完整。
- 曲线容器：大型曲线/圆弧切分模块，形成动态边界。
- 信息密度：中下部组件密集，真实信息可读性仍依赖标题、图例、单位及来源。

## 信息架构
1. 顶部标题与简介。
2. 主视觉：工业/能源场景插画。
3. 中下部：图表与符号模块。
4. 右侧：纵向图标元素索引栏。
5. 底部：地图及其他图表样本。

## 视觉叙事
模板/组件展示型，而非真实数据故事：标题和场景建立主题与风格；图表模块展示可组合表达形式；右侧图标库提供符号资源；各模块独立浏览，非严格线性叙事。

## 制作方法与流程（根据图面推演）
1. 定义模板主题、使用场景、版面比例及组件清单。
2. 建立图标资产清单，按图形可识别语义分类，不猜类别。
3. 设定设计系统：深蓝背景、灰蓝辅助、浅色图标、字号、线宽、描边/填充统一。
4. 制作场景插画：机械主体、城市轮廓、地面与背景分层；区分插画和数据。
5. 规划网格：标题区、主插画区、图表模块区、右侧图标栏。
6. 选择组件样本：饼图、点阵、横条、面积、柱状、地图、重复符号等，统一标题和容器。
7. 转为真实信息图时替换占位文案/假数据，补数据来源、单位、图例、统计口径。
8. 统一右侧图标栏尺寸、间距和基线。
9. 在Illustrator/Figma整合组件，校验对比度、可读性和层级。
10. 导出资产并归档图标目录、组件元数据及案例分析。

## 推荐工具
Illustrator/Figma（图标与版式）、Excel/Python（数据图）、SVG/D3/Plotly（图表组件探索）、CSV（资产索引）。
