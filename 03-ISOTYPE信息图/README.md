# 03 ISOTYPE 信息图专项

本目录是独立的信息图专项项目，用于研究 ISOTYPE（International System of Typographic Picture Education，国际图画教育系统）的历史、原则、视觉语法与当代应用。

ISOTYPE 不作为“02-信息图形类型案例”中的普通图形类型。02 用于归档具体信息图案例及其表达类型；本专项聚焦一套有历史背景、设计原则和方法体系的图像化教育与沟通系统。

## 研究范围

- 历史脉络：从维也纳社会与经济博物馆、奥托·诺伊拉特、玛丽·诺伊拉特及其合作者的实践出发，记录来源与时间线。
- 核心原则：研究图像符号、重复表达数量、简化与标准化、图文协作、面向公众的可理解性。
- 视觉语法：整理符号、单位、组合、排列、图例、尺度与叙事结构；区分可证实原则与后续解释。
- 案例研究：每项研究记录作品来源、作者/团队、年代、图像证据、结构化转录、视觉编码、分析与核验状态。
- 当代应用与批评：考察跨文化可读性、语境、代表性、可访问性及方法适用边界，不将历史原则简单等同于现代图标设计。

## 建议目录

- `研究框架与术语.md`：研究问题、术语、证据等级与方法。
- `历史脉络.md`：人物、机构、出版物及重要节点。
- `视觉语法与原则.md`：符号系统及构图规则，注明来源。
- `案例/`：逐项案例分析与可追溯的数据文件。
- `来源与参考文献.md`：书目、馆藏、档案和在线来源。

## 研究记录规范

1. 区分原始史料明确记载、图面直接观察、研究者推断和待核实信息。
2. 对每条历史或理论主张记录可追溯来源；无法核验的内容明确标注。
3. 不把 ISOTYPE 简化为“一个图标等于一个固定数量”的单条规则；结合具体作品记录符号、单位和布局的语境。
4. 案例资料优先保留来源、许可、原文标签、转录状态和置信度；不擅自补全不可读数据。
5. 若案例同时适用于 02 的某类表达分析，在 02 案例文档中仅作交叉引用，专项理论与系统性研究仍归本目录维护。
