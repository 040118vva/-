## 仓库规则
- [案例入库规则](案例入库规则.md)：先判断五类主导数据逻辑（01），再确定案例标签（02），再拆解视觉编码、信息架构、叙事和制作方法；提取基础数据集；同步迭代定义并更新索引。
- 案例图像/来源资产尽量入库，注明出处和许可；若二进制上传受限，明确记录未上传状态。

## 案例入库流程
1. 接收案例图与来源（如有）。
2. 判断主导数据逻辑，必要时记录复合逻辑。
3. 识别案例类型与表达组件。
4. 分析数据结构、图表方法、视觉编码、信息架构和叙事。
5. 将案例记录归入对应类型文档，并更新数据逻辑定义的原则、边界与方法。
6. 数据逻辑定义文档不嵌入案例图片，使用相对链接指向案例文档。
7. 尽可能整理基础数据集并提交；说明来源、转录状态与限制。
