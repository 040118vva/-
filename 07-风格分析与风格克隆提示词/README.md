# 风格分析与克隆系统

本目录是一套可移植的风格分析与克隆系统，支持三种启动方式，三个入口共用同一套分析规则、风格档案和输出要求。

## 文件

- `风格分析与克隆系统.md`：完整系统指令。可单独上传到网页版大模型，也可放入代码仓库供大模型读取。
- `风格档案模板.json`：建立和保存风格档案的结构模板。
- `记忆调用卡.md`：适合保存到大模型的长期记忆；它负责唤起系统，不替代完整规范。

## 场景一：拖入网页版大模型

将 `风格分析与克隆系统.md` 拖入对话，然后发送：

```text
启动风格分析和克隆系统。先读取并遵循附件中的完整系统规范。接下来我会提供参考图或风格资料。
```

随后上传参考图，或附上需要分析的文档。若希望克隆新主题，再补充主题、主体、用途、画幅等要求。不提供新主题时，系统默认先交付风格档案和四种可复用提示词，不擅自生成新图。

## 场景二：从仓库启动

把本目录放进仓库。启动具备仓库读取能力的大模型后发送：

```text
请读取 outputs/风格分析与克隆系统/风格分析与克隆系统.md，并按其中规范启动风格分析和克隆系统。之后读取我指定的参考图、文档或风格档案。
```

若系统文件在仓库中的位置不同，替换成实际相对路径。若模型无法访问图片或文件，应明确告知并请求用户直接上传或粘贴内容，不得假称已经读取。

## 场景三：大模型已有记忆

把 `记忆调用卡.md` 存入模型可用的长期记忆。之后可直接说：

```text
启动风格分析和克隆系统。
```

或：

```text
用风格档案「档案名称」克隆这张参考图的风格，主题改为：……
```

长期记忆不一定能跨模型、跨账号或跨会话生效。若模型无法提供完整规范，补充上传 `风格分析与克隆系统.md`。使用已保存风格时，最好同时指定档案名称和版本。

## 推荐工作方式

先分析并确认风格档案，再用该档案迁移主题。四种提示词都从同一份确认后的档案生成。主题变化时改主题字段，除非用户明确要求，否则不要修改锁定的风格字段。
