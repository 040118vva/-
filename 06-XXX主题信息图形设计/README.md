# 06 XXX 主题信息图形设计

本项目是单个主题的信息图设计工作区。将“XXX”替换为正式主题名后，按阶段记录研究、数据、叙事、视觉表达、测试与实施过程。

## 工作流程
1. [01-前期调研](01-前期调研/README.md)：明确主题边界与设计任务。
2. [02-主题内容分析](02-主题内容分析/README.md)：与大模型协作分析主题结构。
3. [03-数据搜集](03-数据搜集/README.md)：登记公开数据、文本文献与自建数据。
4. [04-基础数据集构建](04-基础数据集构建/README.md)：建立原子化、可追溯的基础数据表。
5. [05-叙事框架搭建](05-叙事框架搭建/README.md)：以字段组合组织叙事命题。
6. [06-视觉编码](06-视觉编码/README.md)：把数据和叙事转译为视觉表达。
7. [07-信息轮盘测试](07-信息轮盘测试/README.md)：测试维度后续补充。
8. [08-设计实施](08-设计实施/README.md)：制作、评审、修订与交付。

## 文件与数据约定
- 基础数据表采用原子字段，每个单元格只保存一个数据值；复合信息拆分为独立字段或关联表。
- 所有事实、图像、文本转录和模型建议保留来源及核验状态。
- 大模型用于共同分析与提出备选方案；引用的事实须回到原始或可靠来源核实。
- 设计标签可组合使用。数据逻辑、内容载体、视觉风格和具体图表类型分别判断，不混为同一分类维度。
- “信息轮盘测试”目前仅预留章节，方法与判定标准待补充。
