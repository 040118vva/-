# 04 统计图形分析

本目录用于后续整理统计图形的阅读、分析与设计研究。目前仅初始化目录说明，尚未建立统计图形分类文档，也未在此分析或迁移任何现有案例。

## 与现有目录的关系

- [01 信息图形数据逻辑](../01-信息图形数据逻辑/)：按数据组织逻辑归纳信息表达方式；本目录后续可引用相关逻辑，但聚焦统计图形的图表表达与分析。
- [02 信息图形类型案例](../02-信息图形类型案例/)：继续保存现有具体信息图形设计案例。新建本目录不改变其中任何案例、文件或编号。
- [03 ISOTYPE 信息图专项](../03-ISOTYPE信息图/README.md)：独立研究 ISOTYPE 的历史与视觉系统；与统计图形分析相互关联时采用交叉引用，不合并项目内容。

后续若增加图表案例，应遵守仓库的[案例入库规则](../案例入库规则.md)，并保留来源、数据状态及分析依据。
